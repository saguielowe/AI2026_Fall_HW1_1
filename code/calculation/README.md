# 搜索算法计算大题（无编程内容）

这套交互题由五个部分组成：

1. **BFS、DFS、UCS 与 A***：点击图节点录入扩展顺序，并逐步维护 A* 的 frontier 中 `g/f` 记录。
2. **局部搜索与模拟退火**：执行最陡上升爬山法，并逐步计算模拟退火的接受判断与状态变化。
3. **Local Beam Search**：按 `h` 值分两轮选择 `k=2` 个状态，第二轮候选会根据第一轮选择动态展开。
4. **遗传算法**：计算适应度与轮盘赌概率，完成父代选择、单点交叉和指定位反转变异。
5. **Minimax 与 Alpha-Beta 剪枝**：<strong>不计入本次作业成绩，不要求完成，仅供期末复习。</strong>

题目支持“输入学号固定出题”和“随机练习”两种模式。同一学号始终得到同一套题；随机练习每次生成新题。所有生成实例都经过难度筛选。顶部的“检查全部答案”会给出具体到步骤或节点的提示；全部正确后，学号与通过结果会显示在同一区域，便于截图。

## 运行

在项目根目录执行：

```bash
python code/calculation/visualizer.py
```

默认打开 <http://127.0.0.1:8767/>。如果不希望自动打开浏览器：

```bash
python code/calculation/visualizer.py --no-browser --port 8767
```

## 操作指引

1. 正式作答时输入学号并点击“按学号生成”；同一学号每次生成的题目相同。“随机生成练习题”会换一套题，并清空当前作答。
2. 第一至第四部分计入成绩。每部分题干下方都有对应的界面操作提示；第五部分为期末复习，可留空。
3. 完成后点击顶部“检查全部答案”。红色边框和结果区会指出需要重新检查的部分，修改后可反复检查。
4. 全部计分项正确后，页面顶部会显示通过信息。请按作业要求截取包含学号题组和“全部正确”的界面。
