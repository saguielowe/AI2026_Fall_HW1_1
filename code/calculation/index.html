      一

      BFS、DFS、UCS 与 A*

      搜索边界（frontier）的顺序与更新

      从 S 出发搜索 G，使用图搜索，从 frontier 取出节点时才做目标测试。子节点按字母顺序生成；DFS 选择字母序更小的后继先扩展；UCS 按 g 排序，A* 按 f=g+h 排序，平局均按字母顺序。若到同一 frontier 节点的新路径更优，用新路径替换旧路径；已扩展节点不重新打开。
      界面操作：直接点击右侧 BFS、DFS、UCS 或 A* 的答题卡片，再按你认为正确的扩展顺序点击图中节点。界面会自动标记已扩展节点、frontier、当前路径和对应数值；可随时撤销或清空。
      边上是路径代价；节点会实时显示访问状态、当前路径与数值。

      二

      局部搜索与模拟退火

      爬山法、局部最优与概率接受

      目标是最大化状态得分，相邻字母互为邻居。爬山法每次移动到得分最高且严格更优的邻居；模拟退火按照给定候选状态、温度 T 和随机数 r 运行。填写 Δ 和指数 Δ/T（指数保留两位小数）后，界面会自动计算 e^指数并保留两位小数。若 Δ≥0 必定接受，否则在 r<e^(Δ/T) 时移动。每步选择的“下一状态”会自动成为下一步的“当前状态”。
      界面操作：起点已自动记入爬山路径，从下一个状态开始依次点击；误点可撤销。模拟退火逐行填写，先选“下一状态”后，下一行的“当前”会自动更新。
      柱高与数字均表示目标函数值。点击状态，按顺序记录爬山法经过的路径。
